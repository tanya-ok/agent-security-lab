# Security

Agent Security Lab is a local proof of concept for synthetic demonstrations. It
is not a production identity service, a clinical system or a compliance certificate.

Report vulnerabilities privately to the maintainer. If GitHub private vulnerability
reporting is available, use the repository's Security tab. Otherwise use an
already-established private contact channel; do not post credentials, enrollment
links, patient data or exploit details in a public issue.

A useful report identifies the affected revision, the local setup, expected and
observed behavior, and a minimal reproduction using fictional data. Keep raw
runtime logs and secrets out of attachments. There is no promised response SLA.

Only the reviewed local proof-of-concept revision is supported. Dependency and
source-pin updates need review and repeat validation. Browser-only namespace
settings are a display preference; server-side authorization must remain enforced.
