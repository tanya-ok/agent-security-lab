# Dependency review

Upstream releases were checked for the locked lab sources, launcher and standalone
ECS project. New releases are available; no dependency or runtime source pin was
changed during the manual walkthrough.

The detailed inventory, version comparisons and registry digest observations stay
in owner-only local review storage. They are preparation for compatible upgrades,
not a public security advisory or a claim that every dependency is current.

Updates require project checks, strict documentation builds and a fresh local
scenario run. Publication remains subject to private review and owner approval.
